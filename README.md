# 🎂 Animated Birthday Card

A beautiful, interactive, and animated digital birthday card created using HTML, CSS, and JavaScript. 

Specially made for **Aditi**! 🎉

## ✨ Features
* **Interactive Animations:** Features a "Click to Reveal" cover page and a "Make a Wish" cake page.
* **Candle Blow-out Effect:** Includes custom audio sound effects and CSS animations that blow out the virtual candles when clicked.
* **Celebration Mode:** Triggers a shower of colorful confetti and plays a birthday tune!
* **Responsive Design:** Styled using Tailwind CSS to look great on both desktop and mobile devices.
